# 🎓 College Admission Application Form

This is a professional web-based **College Admission Application Form** built using **HTML and CSS**. It allows students to submit their personal and academic details for admission into a college program.

---

## 🌟 Features

- Full Name Input
- Date of Birth Picker
- Gender Selection (Radio Buttons)
- Phone Number & Email Input
- Address Textarea
- Course Selection (Dropdown Menu)
- 12th Marks/Grade Input
- File Upload for Documents
- Declaration Checkbox
- Submit and Reset Buttons

---

## 📁 Files Included

- `index.html` – Main HTML form
- `styles.css` *(optional)* – External CSS (or inline CSS in the HTML file)
- `README.md` – Project description and instructions

---

## 🚀 How to Use

1. Clone or download the repository.
2. Open the `index.html` file in any modern web browser.
3. Fill out the form and click **Submit**.
